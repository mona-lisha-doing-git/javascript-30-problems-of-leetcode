# JavaScript 30 problems of Leetcode
A 30-day coding challenge to solve LeetCode problems using JavaScript, strengthen Data Structures and Algorithms (DSA) concepts, and improve problem-solving skills.

## 🎯 Goals
- Solve 30 LeetCode problems using JavaScript.
- Strengthen understanding of Data Structures and Algorithms.
- Improve coding efficiency and problem-solving skills.
- Maintain consistent coding practice.

## 🛠️ Language Used
- JavaScript (ES6+)

## 📌 Resources
- [LeetCode]([https://leetcode.com/](https://leetcode.com/studyplan/30-days-of-javascript/))
- [JavaScript Documentation](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

## ⭐ Purpose
Consistency over perfection. Learning, practicing, and improving one problem at a time.
